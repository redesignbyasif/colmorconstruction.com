# Colmor Construction homepage

A bespoke, responsive, single-page homepage concept for Colmor Construction, a family-run groundwork and civil engineering contractor serving the Midlands.

## Run locally

Open `index.html` in a browser or serve this folder with any static web server. No build step or runtime dependencies are required. The project is designed for GitHub Pages and uses relative paths for local styles and scripts.

## Brand and research notes

Business details and project examples are based on the public Colmor Construction website. Confirmed public contact details: 0121 222 5313, Info@Colmorconstruction.co.uk, 1 Devon Way, Longbridge, Birmingham, B31 2TS. The original site states the management team has over 40 years of industry experience and that over 90% of projects come from repeat business and reputation.

The existing site photography is referenced from its original public image URLs. Replace with locally licensed/approved assets if an offline image bundle is required. The wordmark in this concept is a newly typeset text treatment, not a copy of the official logo asset. Palette is an interpretation of the existing site's dark charcoal and vivid yellow-green visual identity.

## Deployment

Publish the repository root from the `main` branch in GitHub Pages settings (Settings → Pages → Deploy from a branch → `main` / `/ (root)`). This demo includes `noindex, nofollow` to discourage search indexing. Remove that directive only if the site becomes the canonical production website.
